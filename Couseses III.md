## 🐍 Python & Scientific Computing

> [!ABSTRACT] Core Python, Standard Library, and Data Analysis

* 📊 **[Python for Scientific Computing — Pandas](https://aaltoscicomp.github.io/python-for-scicomp/pandas/)**
  * *Notes:* Aalto Scientific Computing course on Pandas basics and data manipulation.
  * *Repo Link:* [AaltoSciComp/python-for-scicomp (GitHub)](https://github.com/AaltoSciComp/python-for-scicomp)
* 📈 **[Scientific Python — Matplotlib Guide](https://lectures.scientific-python.org/intro/matplotlib/index.html)**
  * *Notes:* Introduction to plotting and data visualization with Matplotlib.
* 📦 **[Real Python — Modules and Packages](https://realpython.com/python-modules-packages/)**
  * *Notes:* In-depth guide on organizing code into reusable modules and packages.
* 📖 **[PyMOTW 3 — Python Module of the Week](https://pymotw.com/3/index.html)**
  * *Notes:* Standard library module walkthroughs with code examples by Doug Hellmann.
* 📕 **[PDF Book — The Python 3 Standard Library by Example](https://github.com/bindrat/PYTHON/blob/main/The%20Python%203%20Standard%20Library%20by%20Example%20(%20PDFDrive%20).pdf)**
  * *Notes:* Stored reference PDF in GitHub repository.

  * *Notes:* Complete free book by William Shotts on mastering the bash terminal.
