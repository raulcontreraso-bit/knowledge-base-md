You can easily add images to your Markdown notes in Obsidian using a few different methods. Here are the most common ways to do it:

### 1. The Standard Markdown Syntax

This is the universal Markdown way to embed an image:

Markdown

```
![Alt text or image name](path/to/image.png)
```

### 2. The Obsidian Shortcut (Drag & Drop)

Obsidian makes this extremely easy without needing to code:

- **Drag and drop:** Simply drag an image file from your computer directly into your open note. Obsidian will automatically copy the image into your vault and generate the correct Markdown code for you.
    
- **Copy and paste:** If you copy an image from the web or your clipboard, just paste it (`Ctrl + V` or `Cmd + V`) directly into your note.
    

### 3. Internal Vault Link Syntax

If you have an image saved inside an attachments folder or your vault, you can use Obsidian's double-bracket shortcut:

Markdown

```
[[my-image-name.png]]
```

_Tip: If you type `[[` and start typing the name of the image file, Obsidian will autocomplete it for you._

### Resizing Images (Optional)

If an image is too large and you want to resize it, you can add a pipe symbol (`|`) followed by the desired width in pixels inside the double brackets:

Markdown

```
[[my-image-name.png|300]]
```
