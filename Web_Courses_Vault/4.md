## 1️⃣ Why the script failed as a `.bat` file

Looking at your screenshot, you saved the file as **`Create_Folders.ps1`**. That extension (`.ps1`) makes it a **PowerShell script**, not a batch script!

If you double-click a `.ps1` file in Windows Explorer, Windows won't run it by default for security reasons.

### 🛠️ Fix Option A: Make it a real `.bat` file (Easiest!)

Batch files use different syntax than PowerShell. In a Batch file, `#` is invalid for comments (use `REM`), and `New-Item` is a PowerShell command.

If you want a file you can **just double-click in Windows Explorer**, create **`setup.bat`** and paste this exact code inside:

DOS

```
@echo off
REM Create module directories
mkdir 01_python\00_vanilla
mkdir 01_python\01_pandas
mkdir 01_python\02_numpy
mkdir 02_frontend
mkdir 03_backend
mkdir .github\workflows

REM Create empty placeholder files
type nul > 01_python\index.md
type nul > 01_python\00_vanilla\01_basics.md
type nul > 01_python\01_pandas\index.md
type nul > 02_frontend\index.md
type nul > 03_backend\index.md

echo Setup complete!
pause
```

_Now double-click **`setup.bat`** in File Explorer—all your folders and files will pop up instantly!_

## 2️⃣ Why are we doing YAML? (`myst.yml` and `deploy.yml`)

YAML (`.yml`) stands for _"YAML Ain't Markup Language"_. It is the industry standard format for **configuration files**.

We are using **two** YAML files in this project, and each has a specific job:

### 1. `myst.yml` $\rightarrow$ The Blueprint of your Web Book

- **What it does:** It tells **Jupyter Book / MyST** how to build your website.
    
- **Why we need it:** Without `myst.yml`, Jupyter Book won't know the website title, author, or the order of pages in your left sidebar navigation menu (Table of Contents).
    

### 2. `deploy.yml` $\rightarrow$ The Robot Instructions for GitHub

- **What it does:** It sits in `.github/workflows/deploy.yml` and contains instructions for **GitHub Actions**.
    
- **Why we need it:** Every time you run `git push`, GitHub reads this file, turns on a cloud server in the background, installs Python and Jupyter Book, compiles your site, and publishes it live to GitHub Pages automatically.

**Spot on! Exactly.**

If this were _just_ a standard GitHub repository for storing code, you wouldn't need `myst.yml` or `deploy.yml` at all. You'd just push your `.py` or `.ipynb` files and call it a day.

Because you are building an **interactive web platform** (a published book/site), those two files act as your bridge from raw files to a live website:

### 🌐 The Difference at a Glance

||**Standard Repo**|**Your Web_Courses_Vault Site**|
|---|---|---|
|**What it is**|A simple folder of files on GitHub.com|A fully styled, searchable web app hosted online|
|**How people view it**|Scrolling through raw code files on GitHub|Browsing a live website with a navigation sidebar|
|**Interactive Code**|Static view only|**Live code execution** right in the browser (via Binder)|
|**Why YAML is needed**|Not needed|**`myst.yml`** builds the sidebar navigation<br><br>  <br><br>**`deploy.yml`** builds the site automatically on `git push`|

### 💡 Think of it like this:

- **Your `.md` & `.ipynb` files** = The content of your book.
    
- **`myst.yml`** = The table of contents and cover design instructions.
    
- **`deploy.yml`** = The automated printing press that publishes your website whenever you add new notes!

## ⚙️ Step 2: Create the GitHub Actions Deployment File

This is the file that tells GitHub to automatically build your website every time you push changes.

1. Open the **`.github`** folder, then open the **`workflows`** folder.
    
2. Inside `workflows`, create a file named **`deploy.yml`**.
    
3. Paste this exact configuration inside `deploy.yml`:
    

YAML

```
name: deploy-book

on:
  push:
    branches:
      - main

jobs:
  deploy-book:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pages: write
      id-token: write
    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install pandas matplotlib jupyter-book sphinx-thebe

      - name: Build the book
        run: |
          jupyter-book build .

      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./_build/html
```
