## 🎨 2. Web Design & Full-Stack Development

Comprehensive full-stack architecture combining classical foundations (LAMP) with modern JavaScript ecosystems and build tooling.

### 💡 Infrastructure Foundation: The LAMP Architecture

```
  L A M P
  │ │ │ └─ PHP / Python (Server-Side Scripting)
  │ │ └─── MySQL / MariaDB (Relational Database)
  │ └───── Apache (Web Server HTTP Routing)
  └─────── Linux (Host Operating System & Permissions)
```

- **Linux:** The underlying open-source operating system providing security, file system management, and server administration.
    
- **Apache HTTP Server:** Web server processing client requests, managing virtual hosts, and routing HTTP traffic.
    
- **MySQL:** Relational database management system (RDBMS) used for structured data models, indexing, and SQL queries.
    
- **PHP:** Server-side scripting language (paired with frameworks like **Laravel**) handling business logic, Eloquent ORM, and RESTful APIs.

## 🖥️ Local & Cloud Deployment Environments

Practical environments utilized for local development, academic testing, and live server deployment:

### 1. Local Development Servers

- **XAMPP (or MAMP / WampServer):** Cross-platform suite bundling Apache, MariaDB/MySQL, and PHP into a single control panel for running Laravel back-ends locally.
    
- **WSL 2 (Windows Subsystem for Linux):** Native Linux (Ubuntu) inside Windows running Apache, MySQL, and PHP directly via terminal (`sudo apt install apache2 mysql-server php`) to match production Linux hosting accurately.
    

### 2. Free Cloud & Server Options (Academic Deployment)

- **Oracle Cloud Free Tier:** Always Free compute instances running custom Apache, MySQL, and PHP stacks on production Linux VMs.
    
- **Render / Fly.io:** Deployment platforms for PHP/Laravel Web Services and managed databases directly integrated with GitHub repositories for capstone project demonstrations.
    
- **Shared PHP Hosting (e.g., InfinityFree):** Apache + MySQL + PHP hosting managed via cPanel/FTP for lightweight scripts and raw HTML/CSS/PHP deployments.
