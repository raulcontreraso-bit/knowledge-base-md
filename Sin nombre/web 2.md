
# 🎓 Master's Degree in Web Design & Full-Stack Development — Roadmap

Welcome to the curriculum repository for the **Master's Degree in Web Design and Web Development**. This repository outlines the academic roadmap, core subjects (60 ECTS), and the complete open-source technology stack utilized throughout the program.

## 💡 What is the LAMP Stack? (Image Explanation)

The logo in the image represents **LAMP**, one of the foundational open-source web development architectures:

```
    L A M P
    │ │ │ └─ PHP / Perl / Python (Server-Side Scripting)
    │ │ └─── MySQL (Relational Database)
    │ └───── Apache (Web Server)
    └─────── Linux (Operating System)
```

### Stack Components:

- **L — Linux:** The underlying open-source operating system providing security, file system management, and server administration.
    
- **A — Apache HTTP Server:** The web server that processes client requests and routes HTTP traffic.
    
- **M — MySQL:** The relational database management system (RDBMS) used for structured data storage and SQL queries.
    
- **P — PHP:** The backend scripting language (paired with frameworks like **Laravel** in modern stacks) that handles business logic and dynamic content generation.
    

In this Master's curriculum, the LAMP stack provides the infrastructure foundation for hosting, database architecture, and server-side backend development.

## 📚 Curriculum Roadmap by Semester

### Semester 1 (18 ECTS)

- [ ] **HTML y CSS** (6 ECTS) — Semantic HTML5, Flexbox, Grid, Responsive Web Design.
    
- [ ] **Diseño de interfaces interactivas** (6 ECTS) — UI/UX design patterns, prototyping, accessibility (WCAG).
    
- [ ] **Programación en JavaScript para programadores** (6 ECTS) — ES6+, asynchronous JS, Promises, DOM API.
    

> _Note: Students requiring preliminary training take **Introducción a la programación en JavaScript I & II** (4 + 4 ECTS)._

### Semester 2 (18 ECTS)

- [ ] **Desarrollo back-end con PHP** (6 ECTS) — PHP 8+, MySQL relational database, RESTful APIs, Laravel MVC.
    
- [ ] **Desarrollo front-end con frameworks JavaScript** (6 ECTS) — Single Page Applications (SPA) with Angular.
    
- [ ] **Herramientas HTML y CSS I** (6 ECTS) — Preprocessors (Sass/SCSS), BEM architecture, CSS modules.
    

### Semester 3 (12 ECTS)

- [ ] **Desarrollo front-end avanzado** (6 ECTS) — Advanced Angular development with TypeScript, type safety, RxJS.
    
- [ ] **Herramientas HTML y CSS II** (6 ECTS) — Modern build tools, Webpack bundling, performance optimization.
    

### Semester 4 (12 ECTS)

- [ ] **Trabajo Final de Máster (TFM)** (12 ECTS) — Full-stack capstone project integrating LAMP/Laravel backend, Angular/TypeScript frontend, and custom web design systems.
